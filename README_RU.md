# SkyTrack 3D — стартовый проект

Веб-приложение в стиле авиатрекера: Cesium-глобус, режим карты с MapLibre GL JS и DEM-рельефом, погодные тайлы OpenWeather, ADS-B-позиции самолётов через OpenSky Network, пользовательские настройки в MongoDB Atlas.

## Что уже есть
- Два режима просмотра: глобус и карта с 3D-рельефом (MapLibre terrain).
- Слои OpenWeather: температура, ветер, осадки, давление, облачность; настройки непрозрачности и насыщенности.
- Слой высотного DEM в режиме карты.
- Запросы живых ADS-B-позиций OpenSky с фильтрацией по видимой области в режиме карты.
- Карточка выбранного самолёта: позывной, ICAO24, страна, высота, скорость, курс, вертикальная скорость.
- Настройки вида, слоя, прозрачности, насыщенности, центра и масштаба хранятся в MongoDB, если указана `MONGODB_URI`.
- Серверный прокси погодных тайлов; ключ OpenWeather не отдаётся фронтенду.

## Развёртывание на Render
1. Создайте новый GitHub-репозиторий, например `skytrack-3d`, и загрузите содержимое ZIP в корень репозитория.
2. Создайте базу в MongoDB Atlas. В **Database Access** создайте пользователя с паролем. В **Network Access** разрешите подключение с Render (для первого теста можно `0.0.0.0/0`, но лучше ограничить доступ, если у вас настроен фиксированный egress). Скопируйте URI вида `mongodb+srv://...`.
3. В OpenWeather создайте API key и убедитесь, что ваш план даёт доступ к нужным погодным тайлам. Некоторые расширенные продукты OpenWeather Maps требуют отдельного плана.
4. В Cesium ion создайте access token и проверьте доступ к Terrain/Imagery assets. Токен нужен для ионных ресурсов; в этом стартовом варианте сервер пока не выдаёт токен браузеру, поэтому глобус может работать без реального terrain-провайдера. См. раздел «Известные ограничения».
5. В Render нажмите **New + → Blueprint**, выберите репозиторий с `render.yaml` и создайте Web Service.
6. В Render → сервис → **Environment** добавьте:
   - `MONGODB_URI` — URI Atlas
   - `MONGODB_DB` — `skytrack`
   - `OPENWEATHER_API_KEY` — ключ OpenWeather
   - `CESIUM_ION_TOKEN` — токен Cesium ion (не публикуйте его в GitHub)
   - `OPENSKY_CLIENT_ID` и `OPENSKY_CLIENT_SECRET` — необязательные OAuth2 credentials OpenSky
7. Нажмите **Manual Deploy → Deploy latest commit**. Проверка сервера: `/api/config`; сайт: `/`.

## Локальный запуск
Python 3.12+:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте `http://127.0.0.1:8000`. Переменные окружения можно задать в панели Render или через локальный shell; не коммитьте реальные ключи.

## API
- `GET /api/config` — статус настроек источников.
- `GET /api/settings` и `PUT /api/settings` — сохранённые настройки. Идентификатор браузера передаётся заголовком `X-Client-Id`.
- `GET /api/flights?lamin=...&lomin=...&lamax=...&lomax=...` — текущие ADS-B state vectors.
- `GET /api/weather-tile/{layer}/{z}/{x}/{y}.png` — серверный прокси тайлов OpenWeather.

## Известные ограничения / перед публичным запуском
1. **Авторизация пользователей пока не реализована.** Сейчас настройки привязаны к случайному ID браузера. Это удобно для прототипа, но не является безопасной системой аккаунтов: для настоящих пользователей добавьте регистрацию, сессии и проверку доступа к настройкам.
2. **Cesium ion terrain:** переменная `CESIUM_ION_TOKEN` передаётся браузеру, так как CesiumJS использует клиентский токен. Создайте отдельный токен, ограничьте его доменом Render и нужными assets; не вставляйте в него административные права. Terrain asset должен быть доступен этому токену.
3. **Высотная палитра:** MapLibre получает DEM и строит объёмный рельеф, но этот прототип пока не раскрашивает поверхность по абсолютной высоте; слой `elevation` показывает DEM-тайлы поверх базовой карты. Для точной высотной раскраски нужен отдельный color-relief raster/terrain RGB shader.
4. OpenSky предназначен прежде всего для исследовательского и некоммерческого использования без отдельного согласования. Коммерческое использование требует разрешения OpenSky. Анонимный доступ ограничен квотами; запрос глобального охвата может быстро исчерпать лимит. Не опрашивайте API чаще, чем необходимо.
5. OpenSky показывает наблюдаемые позиции ADS-B, а не обязательно все самолёты мира. В API нет коммерческого расписания/задержек. Для полного коммерческого продукта сравните лицензированные поставщики (например, ADS-B Exchange, FlightAware, Cirium) и их условия.
6. Текущие погодные тайлы OpenWeather зависят от ключа, тарифа, квот и условий лицензии. Проверьте доступность каждого слоя до публичного запуска.
7. В режиме глобуса текущие рейсы отображаются на эллипсоиде, если Cesium terrain не подключён; MapLibre DEM — отдельный открытый источник высот. Проверяйте атрибуцию и ограничения всех источников перед продакшеном.
8. Для публичного сервиса добавьте серверное кэширование OpenSky, ограничение частоты запросов, логирование, аутентификацию и проверку квот.
